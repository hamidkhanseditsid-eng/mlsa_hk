# Full-Stack Roadmap — Microsoft Learn Edition

A curated, no-fluff path through Microsoft's free official training, picked specifically for people who want to build and ship real web and mobile apps — not collect badges.

Every link below carries my Microsoft contributor ID (`studentamb_574481`). It costs you nothing and changes nothing about the content — it just tells Microsoft the completion came through an ambassador, which is how the program tracks community impact.

Work through the sections in order if you're starting from zero. Skip ahead if you already know a section.

## 1. Version control (start here, no exceptions)

- [ ] [Introduction to Git](https://learn.microsoft.com/en-us/training/modules/intro-to-git/?wt.mc_id=studentamb_574481) — local commits, staging, branching
- [ ] [Introduction to GitHub](https://learn.microsoft.com/en-us/training/modules/introduction-to-github/?wt.mc_id=studentamb_574481) — pull requests, merge conflicts, remote collaboration
- [ ] [GitHub Foundations](https://learn.microsoft.com/en-us/training/paths/github-foundations/?wt.mc_id=studentamb_574481) — Issues, Projects, and the parts of GitHub beyond just `git push`

## 2. Frontend

- [ ] [Build web pages with HTML and CSS for beginners](https://learn.microsoft.com/en-us/training/paths/build-web-pages-html-css-for-beginners/?wt.mc_id=studentamb_574481)
- [ ] [Get started with web development using VS Code](https://learn.microsoft.com/en-us/training/modules/get-started-with-web-development/?wt.mc_id=studentamb_574481) — your editor setup, done right, before it becomes a bad habit
- [ ] [Beginner's Series to: JavaScript](https://learn.microsoft.com/en-us/shows/beginners-series-to-javascript/) — Microsoft retired its old Node.js learning path, so this video series is the current official replacement for core JS concepts
- [ ] [Publish a React, Angular, Vue, or Svelte app with Azure Static Web Apps](https://learn.microsoft.com/en-us/training/modules/publish-app-service-static-web-app-api/?wt.mc_id=studentamb_574481) — pick whichever framework you're already learning; this module is framework-agnostic on purpose

## 3. Backend

- [ ] [ASP.NET Core fundamentals](https://learn.microsoft.com/en-us/training/paths/aspnet-core-fundamentals/?wt.mc_id=studentamb_574481)
- [ ] [Build web apps with ASP.NET Core for beginners](https://learn.microsoft.com/en-us/training/paths/aspnet-core-web-app/?wt.mc_id=studentamb_574481) — C#, Razor Pages, and the request/response cycle
- [ ] [Get started with Python programming: Part 1](https://learn.microsoft.com/en-us/training/paths/get-started-with-python-fundamentals/?wt.mc_id=studentamb_574481) — if your backend stack is Python/Flask/Django instead of .NET

## 4. Databases

- [ ] [Explore relational data in Azure](https://learn.microsoft.com/en-us/training/paths/azure-data-fundamentals-explore-relational-data/?wt.mc_id=studentamb_574481) — SQL Server, PostgreSQL, MySQL, hosted
- [ ] [Develop data-driven applications by using Azure SQL Database](https://learn.microsoft.com/en-us/training/paths/develop-data-driven-app-sql-db/?wt.mc_id=studentamb_574481) — connecting an actual app to an actual database

## 5. Mobile & cross-platform apps

- [ ] [Create a cross-platform app with .NET MAUI](https://learn.microsoft.com/en-us/training/modules/build-mobile-and-desktop-apps/?wt.mc_id=studentamb_574481)
- [ ] [Build mobile and desktop apps with .NET MAUI](https://learn.microsoft.com/en-us/training/paths/build-apps-with-dotnet-maui/?wt.mc_id=studentamb_574481) — one C# codebase targeting iOS, Android, macOS, and Windows

## 6. Cloud, deployment & CI/CD

- [ ] [Azure Fundamentals: Describe cloud concepts](https://learn.microsoft.com/en-us/training/paths/microsoft-azure-fundamentals-describe-cloud-concepts/?wt.mc_id=studentamb_574481) — the vocabulary you need before anything else in this section makes sense
- [ ] [Azure Static Web Apps](https://learn.microsoft.com/en-us/training/paths/azure-static-web-apps/?wt.mc_id=studentamb_574481) — deploy straight from a GitHub repo
- [ ] [Automate your workflow with GitHub Actions — Part 1](https://learn.microsoft.com/en-us/training/paths/github-actions/?wt.mc_id=studentamb_574481)
- [ ] [Automate your workflow with GitHub Actions — Part 2](https://learn.microsoft.com/en-us/training/paths/github-actions-2/?wt.mc_id=studentamb_574481) — CI/CD that runs tests and deploys on every push

## Suggested order

`1 → 2 → 3 → 4`, then `5` and `6` in whichever order matches what you're building next. Don't wait to finish everything before building something — pick a small project after section 3 and pull in the rest as you need it.
